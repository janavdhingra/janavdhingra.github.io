Featured · Mobile web app

EDIT: Daily Style

Picks one outfit a day from your own closet.

EDIT checks the live weather where you are and what's on your calendar, then suggests one main outfit, two alternatives and a short reason for the pick. Calendar events change the choice, so a presentation gets a more formal outfit than a lecture.

The picks come from a scoring system I wrote by hand. It rates each combination on colour harmony, fit balance, formality and warmth, and it adjusts to what you like, save and wear.

  • Calendar sync through a small serverless relay on Netlify.

React · JavaScript · Open-Meteo API · iCal parsing · Netlify Functions · browser storage

Master's research · Machine learning

Prediction intervals for jet engine remaining life

Instead of "74 more flights", the model says "58 to 85 flights, 90% of the time".

This project predicts how many flights a turbofan engine has left before it's unsafe, using NASA's C-MAPSS data. We wrapped LSTM and gradient-boosting models in seven conformal prediction methods, which turn a single guess into a range with a coverage guarantee, and tested that guarantee across 112 combinations of data, model and method.

It held almost everywhere. Where it broke, on the hardest dataset and only for mid-life engines, we used Kolmogorov–Smirnov tests to trace it to calibration and test engines not looking alike, then repaired it with weighted CQR. A frozen-pipeline stress test measured how the guarantee fails when a new fault mode appears.

Python · LSTM & quantile LSTM · gradient boosting · conformal prediction (MAPIE) · KS tests · 63 unit tests

Pixagram

I built this before AI was writing everyone's code. I kinda like it.

An Instagram-style app where you can post photos, like, comment, follow people and see what's trending. Six Spring Boot services sit behind one gateway that checks your login token on every request, and each service keeps its own MySQL database. One docker-compose up starts all seven containers.

Trending hashtags get pulled out of captions as you post. The Caption Studio writes captions in four tones and tags every post with one of seven vibes, using hand-written keyword lists and templates.
